# Quickstart: Extraction Profiles Command

**Feature**: 007-extraction-profiles
**Date**: 2026-02-19

## What This Feature Does

Adds a `/reforge.profile` command that generates language-specific and architecture-specific extraction guidance stored in `.reforge/memory/extraction-profile.md`. The extract command loads this profile automatically. The hardcoded language-specific rules are removed from extract.md.

After implementation:
1. Users run `/reforge.profile` to declare (or auto-discover) their tech stack
2. The command generates a tailored extraction profile in memory
3. `/reforge.extract` automatically loads the profile for language-aware extraction
4. Without a profile, extraction still works but without language-specific rules

## Prerequisites

- Branch `007-extraction-profiles` checked out
- Current `.reforge/commands/extract.md` at ~1048 lines (post spec-006 modifications)
- Access to `.reforge/commands/init.md` as reference for interactive command pattern

## Troubleshooting

**Line numbers don't match**: If extract.md has been modified since this plan was created, use semantic anchors (section headers like "## Language-Specific Extraction Rules" and "### Step 0.5: Load Project Context") instead of line numbers.

**Agent-specific language found**: If generated profile content references specific AI agents (Claude, Copilot), replace with "the agent" or "you" per Constitution Principle V.

**Auto-discovery returns too many languages**: The profile command should filter to languages with significant file counts (e.g., >5 files) and present results sorted by file count for user confirmation.
