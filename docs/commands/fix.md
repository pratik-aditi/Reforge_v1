# /reforge.fix

Execute corrections from the audit correction plan.

## Syntax

```
/reforge.fix [--type <type>] [--items <ids>] [--interactive] [--resume] [--json]
```

## Arguments

| Argument | Required | Description |
|----------|----------|-------------|
| `--type` | No | Limit to corrections for a specific extraction type (e.g., `business-rules`) |
| `--items` | No | Execute only specific correction IDs (comma-separated, e.g., `COR-001,COR-003`) |
| `--interactive` | No | Prompt for confirmation before each correction |
| `--resume` | No | Resume from last checkpoint after interruption |
| `--json` | No | Output fix results as JSON for tooling integration |

## What It Does

This command reads the correction plan generated by `/reforge.audit` and executes corrections in dependency order:

1. **Analysis corrections** -- re-analyze stale files first (dispatches to `/reforge.reanalyze`)
2. **Extraction corrections** -- re-extract or fill gaps after analysis is current (dispatches to `/reforge.extract`)
3. **Generation corrections** -- regenerate affected outputs (dispatches to `/reforge.generate`)

Each correction is verified after execution: the command checks that gaps have been filled, stale references updated, and fabricated entries removed. Failed corrections are logged and can be retried with `--resume`.

The `--interactive` flag pauses before each correction, showing details and prompting for `yes`, `skip`, or `abort`. The command supports checkpointing -- interrupt at any time and resume with `--resume`.

## Prerequisites

- Completed audit with correction plan (`reforge_output/<project>/audit/correction-plan.xml` must exist)

## Output

- Updated extraction and analysis XML files
- Updated `correction-plan.xml` with completion status per item
- Checkpoint file at `.reforge/memory/checkpoints/fix-checkpoint.xml` (removed on full completion)

## Example

=== "Claude Code"

    ```
    /reforge.fix
    /reforge.fix --type business-rules
    /reforge.fix --items COR-001,COR-003
    /reforge.fix --interactive
    /reforge.fix --resume
    ```

=== "GitHub Copilot"

    ```
    @reforge.fix
    @reforge.fix --type business-rules
    @reforge.fix --items COR-001,COR-003
    @reforge.fix --interactive
    @reforge.fix --resume
    ```
