# HTML Index Page Template

> Template for the master index page that links all generated HTML documents

## Template Variables

| Variable | Source | Description |
|----------|--------|-------------|
| `{{project.name}}` | Config | Project name from `config.json` |
| `{{document.date}}` | Generated | Generation date in `YYYY-MM-DD` format |
| `{{total_extractions}}` | Computed | Count of extraction types with data |
| `{{total_items}}` | Computed | Total extracted items across all types |
| `{{coverage_pct}}` | Computed | Overall extraction coverage percentage |
| `{{documents}}` | Computed | Array of generated document entries |

## Document Inventory Population

The agent MUST populate the document inventory tables by:

1. Reading the file manifest produced during the "Plan Document Set" step
2. Categorizing each document into Core, Extended, Derived, or Diagrams
3. Including item counts from the canonical metrics registry
4. Linking to the correct filename (including sub-index pages for split types)

### Category Mapping

| Category | Extraction Types |
|---|---|
| Core Extractions | `business-rules`, `database`, `ui`, `workflows` |
| Extended Extractions | `call-sites`, `dependencies`, `functional-requirements`, `non-functional`, `architecture`, `issues` |
| Derived Artifacts | `cross-mappings`, `features`, `registries` |
| Diagrams | Any standalone diagram collections |

### Split Type Handling

When a type has been split into sub-files, the index table MUST:
- Link to the sub-index page (`{type}-index.html`), not individual sub-files
- Show the total item count across all sub-files
- Append "(N sub-documents)" to the title
