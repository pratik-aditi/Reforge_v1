# Cross-Mappings Schema

> Defines the structure for traceability matrix (`cross-mappings.xml`)

## Overview

The cross-mappings schema captures the traceability relationships between features, requirements, business rules, workflows, UI components, and source files. Generated by `/reforge.generate cross-mappings`.

## Root Element

```xml
<cross-mappings project-id="my-app" version="1.0.0"
                generated="2024-01-15T10:30:00Z">
  <traceability-matrix>...</traceability-matrix>
</cross-mappings>
```

### Attributes

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `project-id` | string | Yes | Reference to analysis project |
| `version` | string | Yes | Schema version |
| `generated` | dateTime | Yes | Generation timestamp |

## Elements

### `<traceability-matrix>`

Container for all trace entries.

```xml
<traceability-matrix count="12">
  <trace>...</trace>
</traceability-matrix>
```

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `count` | integer | Yes | Total trace entries |

### `<trace>`

Individual feature trace linking all related artifacts.

```xml
<trace feature="FT-001" name="Order Submission">
  <functional-requirements>
    <ref id="FR-001">Customer can submit a new order</ref>
    <ref id="FR-002">Order total is calculated with discounts</ref>
  </functional-requirements>
  <business-rules>
    <ref id="BR-001">Apply volume discount</ref>
    <ref id="BR-002">Validate order has items</ref>
  </business-rules>
  <workflows>
    <ref id="WF-001">Order submission workflow</ref>
  </workflows>
  <ui-components>
    <ref id="CMP-001">Submit order button</ref>
    <ref id="SCR-002">New order form screen</ref>
  </ui-components>
  <source-files>
    <file path="src/controller/OrderController.java" role="entry-point" lines="50-95"/>
    <file path="src/service/PricingService.java" role="business-logic" lines="45-52"/>
    <file path="src/repository/OrderRepository.java" role="data-access"/>
  </source-files>
</trace>
```

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `feature` | string | Yes | Feature ID (FT-XXX) |
| `name` | string | Yes | Descriptive feature name |

### `<ref>`

Reference to an extracted artifact within a trace category.

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | string | Yes | Artifact ID (BR-XXX, FR-XXX, WF-XXX, etc.) |

Text content provides a brief description.

### `<file>`

Source file reference within a trace.

| Attribute | Type | Required | Description |
|-----------|------|----------|-------------|
| `path` | string | Yes | Relative file path |
| `role` | string | Yes | Role in the feature (entry-point, business-logic, data-access, ui-template, etc.) |
| `lines` | string | No | Relevant line range (e.g., "50-95") |

---

## Example

```xml
<?xml version="1.0" encoding="UTF-8"?>
<cross-mappings project-id="legacy-ecommerce" version="1.0.0"
                generated="2024-01-15T14:00:00Z">

  <traceability-matrix count="3">
    <trace feature="FT-001" name="Order Submission">
      <functional-requirements>
        <ref id="FR-001">Customer can submit a new order</ref>
        <ref id="FR-002">Order total is calculated with applicable discounts</ref>
      </functional-requirements>
      <business-rules>
        <ref id="BR-001">Apply 10% discount for orders over $100</ref>
        <ref id="BR-002">Order must have at least one item</ref>
      </business-rules>
      <workflows>
        <ref id="WF-001">Order submission workflow</ref>
      </workflows>
      <ui-components>
        <ref id="CMP-011">Submit order button</ref>
        <ref id="SCR-002">New order form</ref>
      </ui-components>
      <source-files>
        <file path="src/controller/OrderController.java" role="entry-point" lines="50-95"/>
        <file path="src/service/PricingService.java" role="business-logic" lines="45-52"/>
        <file path="src/repository/OrderRepository.java" role="data-access"/>
        <file path="webapp/orders/new.jsp" role="ui-template"/>
      </source-files>
    </trace>

    <trace feature="FT-002" name="Customer Management">
      <functional-requirements>
        <ref id="FR-003">Admin can view customer list</ref>
      </functional-requirements>
      <business-rules>
        <ref id="BR-010">Customer email must be unique</ref>
      </business-rules>
      <workflows>
        <ref id="WF-005">Customer registration workflow</ref>
      </workflows>
      <ui-components>
        <ref id="SCR-005">Customer list screen</ref>
      </ui-components>
      <source-files>
        <file path="src/controller/CustomerController.java" role="entry-point"/>
        <file path="src/service/CustomerService.java" role="business-logic"/>
      </source-files>
    </trace>
  </traceability-matrix>

</cross-mappings>
```
